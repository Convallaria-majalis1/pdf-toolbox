# PDF 批处理器 v1.0

> 合并、拆分、加水印、提取文字——四个最常被问到的 PDF 需求，一个工具全包。
> 所有结果都写成新文件，原始 PDF 不会被改动。

---

## 一、四个功能

| 功能 | 解决什么 | 典型场景 |
|---|---|---|
| **合并** | 把多个 PDF 按指定顺序拼成一个，自动加书签 | 合同附件、报销凭证、多份报告合成一本 |
| **拆分** | 每页拆开 / 每 N 页一个 / 只提取指定页码 | 一份 200 页的册子拆成单页发群、抽第 3-5 页单独发 |
| **加水印** | 批量加页码、日期、公司名，位置字号角度可调 | 投标文件加"仅供评审"、合同加页码、资料加公司名 |
| **提取文字** | 把 PDF 里的文字抽到一个 txt，带页码标记 | 把扫描版通知转成可复制文本、批量收集报告内容 |

## 二、各功能的细节

### 合并

- 列表顺序就是拼接顺序，用"上移/下移"调
- 勾选"加书签"后，阅读器左侧目录会按文件名分节
- 每个文件后面的"（N 页）"是实时读出来的，加密文件会标"（加密）"

### 拆分

| 方式 | 结果 |
|---|---|
| 每页单独一个文件 | `合同_001-001.pdf`、`合同_002-002.pdf`… |
| 每 N 页一个文件 | 每 N 页切一刀，最后一个文件可能不满 N 页 |
| 只提取指定页码 | 把选中的页合成**一个新文件** |

页码表达式语法：

| 写法 | 含义 |
|---|---|
| `3` | 只要第 3 页 |
| `1-5` | 第 1 到第 5 页 |
| `1-3,7,9-` | 第 1-3 页、第 7 页、第 9 页到最后一页 |
| `-4` | 从第 1 页到第 4 页 |

页码超出范围会直接报错并告诉你总页数，不会静默出错。

### 加水印

文字里可以用四个占位符：

| 占位符 | 会被替换成 |
|---|---|
| `{page}` | 当前页码 |
| `{total}` | 总页数 |
| `{date}` | 今天的日期 |
| `{filename}` | 原文件名（不含扩展名） |

常用写法：

- `第 {page} 页 / 共 {total} 页` —— 最标准的页码
- `仅供 XX 公司内部使用  {date}` —— 保密水印
- `{filename}  {page}/{total}` —— 溯源水印

参数说明：位置是九宫格（左上到右下），透明度 0.1~1.0，角度支持 0/±45/±90，**从第几页开始**可以让封面不加页码。取消"盖在内容上方"就会放到内容下层。

### 提取文字

- 输出一个 txt，用 `===== 文件名 =====` 和 `--- 第 N 页 ---` 分段
- 空页会被统计出来，处理完的提示里会告诉你有几页没提到文字
- 扫描件提不出字是正常的，需要 OCR，本工具不做（下面"能力边界"里写了）
