# PDF 批处理器 v1.0

> 合并、拆分、加水印、提取文字——四个最常被问到的 PDF 需求，一个工具全包。
> 所有结果都写成新文件，原始 PDF 不会被改动。

---

## 一、四个功能

| 功能 | 解决什么 | 典型场景 |
|---|---|---|
| **合并** | 把多个 PDF 按指定顺序拼成一个，自动加书签 | 合同附件、报销凭证、多份报告合成一本 |
| **拆分** | 每页拆开 / 每 N 页一个 / 只提取指定页码 | 一份 200 页的册子拆成单页发群、抽第 3-5 页单独发 |
| **加水印** | 批量加页码、日期、公司名，位置字号角度可调 | 投标文件加"仅供评审"、合同加页码、资料加公司名 |
| **提取文字** | 把 PDF 里的文字抽到一个 txt，带页码标记 | 把扫描版通知转成可复制文本、批量收集报告内容 |

---

## 二、快速开始

```bat
python -m pip install -r requirements.txt
python main.py
```

或者双击 `运行.bat`（会自动装依赖）。

用 `示例PDF/` 里的三个文件练手：

- `合同_2026.pdf`（5 页，有文字）
- `报价单.pdf`（3 页，有文字）
- `扫描件_无文字.pdf`（2 页，只有图形，模拟扫描件）

### 建议按这个顺序试一遍

1. **合并**：添加 `合同_2026.pdf` + `报价单.pdf`，点"开始合并" → 得到 8 页的 `合并结果.pdf`
2. **拆分**：添加 `合同_2026.pdf`，方式选"每 2 页一个文件" → 得到 3 个文件（2+2+1 页）
3. **加水印**：添加 `报价单.pdf`，文字保持默认 `第 {page} 页 / 共 {total} 页` → 每页右下角出现页码
4. **提取文字**：三个文件一起提取 → 得到 `提取文字.txt`

第 4 步会提示"有 2 页没有提取到文字"，这正是扫描件的特征——**这个提示本身就是卖点**，说明工具能帮你判断哪些 PDF 需要 OCR。

## 三、各功能的细节

### 合并

- 列表顺序就是拼接顺序，用"上移/下移"调
- 勾选"加书签"后，阅读器左侧目录会按文件名分节
- 每个文件后面的"（N 页）"是实时读出来的，加密文件会标"（加密）"

### 拆分

| 方式 | 结果 |
|---|---|
| 每页单独一个文件 | `合同_001-001.pdf`、`合同_002-002.pdf`… |
| 每 N 页一个文件 | 每 N 页切一刀，最后一个文件可能不满 N 页 |
| 只提取指定页码 | 把选中的页合成**一个新文件** |

页码表达式语法：

| 写法 | 含义 |
|---|---|
| `3` | 只要第 3 页 |
| `1-5` | 第 1 到第 5 页 |
| `1-3,7,9-` | 第 1-3 页、第 7 页、第 9 页到最后一页 |
| `-4` | 从第 1 页到第 4 页 |

页码超出范围会直接报错并告诉你总页数，不会静默出错。

### 加水印

文字里可以用四个占位符：

| 占位符 | 会被替换成 |
|---|---|
| `{page}` | 当前页码 |
| `{total}` | 总页数 |
| `{date}` | 今天的日期 |
| `{filename}` | 原文件名（不含扩展名） |

常用写法：

- `第 {page} 页 / 共 {total} 页` —— 最标准的页码
- `仅供 XX 公司内部使用  {date}` —— 保密水印
- `{filename}  {page}/{total}` —— 溯源水印

参数说明：位置是九宫格（左上到右下），透明度 0.1~1.0，角度支持 0/±45/±90，**从第几页开始**可以让封面不加页码。取消"盖在内容上方"就会放到内容下层。

### 提取文字

- 输出一个 txt，用 `===== 文件名 =====` 和 `--- 第 N 页 ---` 分段
- 空页会被统计出来，处理完的提示里会告诉你有几页没提到文字
- 扫描件提不出字是正常的，需要 OCR，本工具不做（下面"能力边界"里写了）

## 五、能力边界（跟客户说清楚，避免扯皮）

| 能做 | 不做 |
|---|---|
| 合并、拆分、提取页 | OCR（把扫描图片识别成文字） |
| 加文字水印（含中文） | 加图片水印 / LOGO 水印 |
| 提取文字型 PDF 的文字 | 保留原排版地导出 Word |
| 处理未加密的 PDF | 破解加密 PDF（需要客户先给密码解密） |
| 按页码范围操作 | 按书签、按章节自动拆分 |

**特别提醒**：给客户交付时一定要说"扫描件提不出文字"，否则他会拿一堆扫描 PDF 来试，然后说你的工具坏了。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 提示"加密 PDF，需要密码" | 文件有打开密码 | 让客户先用阅读器另存一份无密码版本 |
| 水印中文变成方块 | 字体没注册成功 | 本工具用的是 reportlab 内置 CID 字体，正常不会出现；若出现，把文件名发我 |
| 合并后顺序不对 | 列表顺序就是拼接顺序 | 用"上移/下移"调整 |
| 提取出来全是空行 | 扫描件 | 需要 OCR，不在本工具范围 |
| 拆分出的文件太多 | 选了"每页单独" | 改成"每 N 页" |
| 大文件处理慢 | 单线程逐页处理 | 属正常，200 页大约十几秒 |

```
├── generate_samples.py  # 生成测试 PDF

├── 运行.bat             # 双击运行

```

命令行也能用，方便批量测试：

```bat
python core.py merge 示例PDF\合同_2026.pdf 示例PDF\报价单.pdf -o 合并.pdf
python core.py split 示例PDF\合同_2026.pdf -d 拆分包 --mode every --pages 2
python core.py watermark 示例PDF\报价单.pdf -o 带页码.pdf --text "第 {page} 页 / 共 {total} 页"
python core.py extract 示例PDF\合同_2026.pdf -o 文字.txt
python core.py info 示例PDF\合同_2026.pdf
```
